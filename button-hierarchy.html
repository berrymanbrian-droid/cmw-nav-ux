Action-by-action audit

Current button What it does today Recommendation
Timeline — your tests by date Opens a separate chronological view of all tests. Demote

Not relevant as a first-tier button. Sorting the table by date already satisfies this. Replace with a quiet link at the bottom of the table: "View all tests in timeline →".
Select tests to group Enters a mode where you pick multiple tests to batch into a group/project. Replace with table pattern

Use a standard checkbox in the table header (select-all) plus a checkbox per row. Selecting rows reveals a bulk-action bar (Group, Move, Share). This is the expected pattern and removes the extra button + mode.
Projects — your lines of inquiry Jumps to the Projects view. Remove

Redundant — the Projects pill directly above already does this. Drop the duplicate button.
Sort / "then" / Date code / Newest first × A multi-level sort builder (primary sort, secondary sort, direction) sitting inline. Consolidate

Collapse into clickable column headers with sort carets. Click a header to sort; click again to flip direction. Removes the inline multi-level sort builder.
New glaze Primary create action. Keep

Keep as the one filled primary button, right-aligned.
List / Tiles / Chemistry View switchers for the result set. Keep

Keep as a grouped segmented control, right-aligned next to New glaze.
Present (per row) A full "Present" button repeated on every row. Demote

Replace the repeated button with a compact icon + tooltip in a row-actions column. Lighter, less visual noise.
Import / Drop Box / Bulk photos Separate import actions scattered in the toolbar. Consolidate

Gather under a single "Import files & images" menu placed above the table, so it applies across material types.
Active / Archived / All / By project tabs No clear way to separate in-progress tests from archived ones, or to view them grouped. New

Add a filter tab row above the table: Active tests (default — hides archived), Archived, All tests, and By project (grouped). Each shows a count so the distribution is visible at a glance.
Filters + results count Faceted filters existed as scattered dropdowns; no summary of how many results are showing. Consolidate

Collect facets (Status, Photos, Surface, Color family, Flux type) into one Filters panel, and add a "Showing X of Y" count above the table.
